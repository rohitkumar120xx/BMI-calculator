# BMI Calculator 🧮

A simple and responsive **BMI (Body Mass Index) Calculator** built using **HTML, CSS, and JavaScript**.

This project allows users to enter their height and weight and instantly calculate their BMI along with the corresponding BMI category.

## 🚀 Features

* Calculate BMI instantly
* Simple and user-friendly interface
* Responsive design
* BMI category/result display
* Input validation
* Built with pure HTML, CSS & JavaScript
* Works directly in the browser

## 🛠️ Technologies Used

* **HTML5** – Structure of the website
* **CSS3** – Styling and responsive design
* **JavaScript** – BMI calculation and functionality

## 📐 BMI Formula

The BMI is calculated using:

```text
BMI = Weight (kg) / Height² (m²)
```

### BMI Categories

| BMI         | Category      |
| ----------- | ------------- |
| Below 18.5  | Underweight   |
| 18.5 – 24.9 | Normal Weight |
| 25 – 29.9   | Overweight    |
| 30 or above | Obesity       |

> **Note:** BMI is a general screening measure and does not account for factors such as muscle mass, age, or body composition.
